# HSK 语料库数据画像

## 1. 分析概述

本阶段对 HSK 动态作文语料库 3.0 的错句检索数据进行初步画像，主要包括数据基本质量检查和偏误标注结构分析，旨在了解数据特征、识别潜在质量问题，为后续数据清洗、标准化及多语料库整合提供依据。

数据由官网分组导出的 6 个 CSV 文件合并得到，原始数据保持不变。

- **总记录数**：155,643
- **字段数**：16
- **不同作文编码数**：11,334
- **核心字段**：作文编码、学习者背景信息、考试成绩、检索原句等

其中，`record_id` 为合并后生成的记录标识，`作文编码` 为作文标识，不等同于学习者唯一标识。

## 2. 数据基本画像

使用 `src/profile_hsk.py` 检查字段类型、缺失值、重复记录及异常取值。

| 检查项目 | 结果 |
|---|---|
| 完全重复记录 | 112 条 |
| 内容相同但来源记录不同 | 198 条（86 组） |
| 口试、作文分数同时缺失 | 672 条，涉及 68 篇作文 |
| 考试时间月份为 `00` | 2,559 条 |
| 其他非法月份及时间格式异常 | 0 条 |

其中，月份为 `00` 的考试时间包括 `199200`（672 条）和 `199500`（1,887 条）。

**处理原则**：当前阶段以识别和记录问题为主，不直接删除重复记录、填补缺失值或修改异常时间。后续根据具体分析任务确定清洗规则。

## 3. 偏误标注画像

使用 `src/profile_annotations.py` 对 `检索原句` 字段进行括号结构检查、篇章标注边界分析及偏误编码频次统计。

### 3.1 标注结构

| 检查项目 | 记录数 | 占比 |
|---|---:|---:|
| 含至少一对匹配括号 | 104,060 | 66.86% |
| 未检测到匹配括号 | 51,583 | 33.14% |
| 含花括号标注 | 71,518 | 45.95% |
| 含方括号标注 | 71,333 | 45.83% |
| 同时包含两类括号 | 38,791 | 24.92% |
| 存在嵌套括号 | 5,217 | 3.35% |
| 疑似括号不匹配 | 2,625 | 1.69% |

上述统计基于括号配对规则，不代表已完成偏误编码合法性验证。

### 3.2 篇章标注边界

对 2,625 条疑似括号不匹配记录进一步检查：

- **2,591 条**包含 `{CP` 或 `P}` 篇章标注边界。
- **34 条**未检测到上述边界标记。

由于 `{CP ... P}` 可能跨越多个句子，单条错句记录中的括号不完整不一定属于数据错误。其余 34 条仍需进一步核验。

### 3.3 偏误编码统计

依据官方标注说明整理编码规则表 `config/hsk_annotation_codes.csv`，区分固定编码、参数化编码及待确认编码，采用规则匹配进行提取。

- **已识别编码种类**：66 种（具体编码形式）
- **已识别编码总出现次数**：291,126 次
- **待核验候选**：611 条

待核验候选主要涉及编码边界歧义、数字参数歧义、未确认编码及括号不完整等情况。

**局限性**：编码统计采用保守匹配策略，未完成全面人工核验；待核验候选不能直接视为错误记录，已识别结果也不等同于完全准确的偏误统计。

## 4. 阶段结论

本阶段完成了数据基本质量与偏误标注结构的初步画像，明确了缺失值、重复记录、时间占位值及篇章标注边界等需要关注的问题。

后续将保留原始数据及标注信息，根据多语料库整合需求制定字段映射和标准化规则。偏误编码的进一步解析与核验则根据具体研究任务开展，不作为多源数据整合的前置条件。
